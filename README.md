# 🌡️ Temperature Converter

A simple and interactive temperature conversion web application built with **HTML, CSS and JavaScript**.

This project allows users to convert temperatures between **Celsius (°C)** and **Kelvin (K)** through a clean and easy-to-use interface.

## 🚀 Features

- Convert Celsius to Kelvin
- Convert Kelvin to Celsius
- Simple and user-friendly interface
- Radio buttons for selecting the conversion type
- Instant conversion results
- Input validation for missing conversion selections

## 🛠️ Technologies Used

- HTML5
- JavaScript
- CSS3
